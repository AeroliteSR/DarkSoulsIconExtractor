# Replacing Textures

Replacement begins by pressing the "Replace Selected Texture" button (Fig. 6 in [Introduction](introduction.md)).  

You will be prompted for an image file. Ideally, this should be png or dds, but any PIL compatible format should work.
The image should probably be of the same size and aspect ratio as the icon you're replacing, but otherwise, DSTS will scale it using LANCZOS resampling.

Replacements can be reverted using the right click context menu.
