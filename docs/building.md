### Build from source:
Clone the repository:  
`git clone https://github.com/dash512/DarkSoulsTextureStudio.git`  
`cd DarkSoulsTextureStudio`  

Install requirements:  
`pip3 install rich constrata PySide6 Pillow`

Either run `DSTS.py` or compile using:  
`python setup.py build` (requires cx_Freeze)
